# 🚀 Fastify Prisma PostgreSQL Starter

A **production-ready backend starter template** built with modern best practices using:

- ⚡ Fastify
- 🧠 TypeScript
- 🗄️ Prisma ORM
- 🐘 PostgreSQL
- ✅ Zod (schema validation)
- 📘 Swagger (API documentation)
- 🔐 CORS
- 🔁 Hot reload with tsx

Designed to scale from **small projects** to **large production-grade APIs**.

---

## ✨ Features

- Modular, scalable folder structure
- Environment validation with Zod
- Prisma integration with Fastify plugin
- Centralized route registration
- API documentation via Swagger
- Type-safe request validation
- Clean dev & production separation
